# Enough YouTube for Today
A firefox extension for countering YouTube addiction. Supports auto-acceleration, disabling infinite scroll, blocking shorts/comments/suggestions. You can also set time limits directly.

## Details
* Hide certain parts of the webpage from sight, e.g. shorts, comment section, suggested videos (right side of a watch page).
* Disable infinite scrolling, or disable scrolling entirely.
* Set a default playback speed (theoretically won't affect music videos).
* Set watch time for every week day, if it's not watch time the addon will cover the whole screen with a reminder message to force you quit.

Some features may not available if your firefox version is older then [147](https://www.firefox.com/en-US/firefox/147.0/releasenotes/).
